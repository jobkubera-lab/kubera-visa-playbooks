# CONTRIBUTING

Thank you for your interest in contributing!

---

## How to contribute

### 1. Report issues

Found outdated information or an error?

**Open an issue with:**
- What the problem is
- Where it is (file and section)
- How to fix it (if you know)
- Current year/source

### 2. Suggest improvements

- New countries or visa types
- Better explanations
- Updated timelines or requirements
- Helpful resources and links

### 3. Submit changes

**For small updates:**
- Fork the repository
- Make your changes
- Submit a PR

**For major changes:**
- Open an issue first
- Discuss with maintainers
- Then submit PR

---

## Standards

- Use clear, plain language
- Cite official government sources
- Mark information as verified/estimated
- Update last-checked date
- Link to official resources
